Using the map

Click a county to select or deselect it. Select multiple counties before choosing a destination state.

Click Move, then click a county in the state that should receive the selection. The current map engine recalculates state totals after the move.

Hold Q while moving the pointer over counties to select them, or hold W to deselect them. M toggles move mode, and P switches the details table between raw votes and percentages.

The map can be zoomed and panned. The information pane can be resized using the divider or the pane-size control above it.

The current version supports moving counties between existing states. Creating additional states and displaying geographic metrics will be added through the new state model.

About this project

Redraw the States is an interactive tool for exploring hypothetical state boundaries and their associated data.

This public development fork is maintained by Eric Sundberg. The original project was created by Kevin Hayes Wilson and contributors. Original authorship and Git history are preserved.

View the development fork · View the original repository

The inherited election calculations are simplified and the available datasets have documented limitations. They should not be treated as official election results. Data provenance and modeling assumptions are being expanded as part of this fork.
